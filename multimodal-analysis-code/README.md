# Multimodal SHG and Mid-IR Analysis Code

This repository contains the analysis code used in the manuscript. It includes separate workflows for mid-infrared (mid-IR) spectral analysis and multimodal analysis that combines second-harmonic generation (SHG) imaging with mid-IR spectroscopy.

## Repository structure

| Directory | Description |
| --- | --- |
| [`src_multimodal/`](./src_multimodal/) | Multimodal SHG and mid-IR analysis, including feature fusion and linear discriminant analysis (LDA) of the combined SHG imaging and mid-IR spectral features. |
| [`src_spectal/`](./src_spectal/) | Mid-IR spectral analysis of measurements acquired on calcium fluoride (CaF₂) substrates, including spectral preprocessing and feature extraction. |
